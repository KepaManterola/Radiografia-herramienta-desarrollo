# Radiografía de Visual Studio Code

## ¿Qué es Visual Studio Code?

Visual Studio Code es un editor de código gratuito que se utiliza para programar. Permite trabajar con diferentes lenguajes como HTML, CSS y JavaScript. También tiene extensiones que permiten añadir nuevas funciones.

## Funcionalidades de la página

En esta actividad he añadido varias funciones utilizando JavaScript:

- Un botón que cambia un mensaje al pulsarlo.
- Un mensaje que aparece en la consola del navegador.
- Un botón para mostrar y ocultar información sobre Visual Studio Code.
- Una lista con algunas características del programa.
- Un buscador para encontrar características por su nombre o descripción.
- Un mensaje cuando no se encuentran resultados.

## Archivos del proyecto

- `index.html`: contiene la estructura de la página.
- `css/style.css`: contiene los estilos.
- `js/main.js`: controla los botones y el buscador.
- `js/datos.js`: contiene las características de Visual Studio Code.
- `js/interfaz.js`: crea y muestra las características en la página.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Cómo abrir la página

Para ejecutar el proyecto desde Visual Studio Code:

1. Abrir la carpeta del proyecto.
2. Instalar la extensión Live Server si todavía no está instalada.
3. Abrir el archivo `index.html`.
4. Hacer clic derecho y seleccionar `Open with Live Server`.
5. La página se abrirá en el navegador.

## Cliente y servidor

El cliente es el navegador, que solicita los archivos necesarios para mostrar la página. El servidor entrega los archivos HTML, CSS y JavaScript. El navegador interpreta el HTML, aplica los estilos y ejecuta el JavaScript. Para comprobarlo, he abierto las herramientas de desarrollador, he entrado en la pestaña Red y he recargado la página para ver cómo se cargan los archivos.
